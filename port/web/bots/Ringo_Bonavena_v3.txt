'Ringo Bonavena v3
'Liga: F1 (torneos del port; ajustado con la receta anti-pasivos:
'tope 5000 por energia, AGECOST 1, 100 bots por especie)
'El pesado de v1 (ojos en abanico, golpe al cuerpo con shootval, shell
'y poison, division con sobra), sin las muertes subitas de v2:
'- Pariente por el ADN del que mira (conteos .refeye/.refshoot/...), no
'  por .out1: Rabidus copiaba la firma y Ringo no le tiraba.
'- Lazos ajenos cortados cada ciclo y sin tirar mientras esta atado:
'  lo que un lazo escribe (Spinner: .shootval 31999) llega despues del
'  ADN y antes del tiro, y ese -6 le costaba toda la energia.
'- Slime 500 contra virus (Rabidus, DIN2) y limpieza al final del ADN:
'  .vshoot/.mkvirus/.delgene a 0 y .repro solo 0 o 20.
'- Poison nunca menos de 300 (rechaza los lazos que chupan 1000).
'- Ojo central ancho y acercamiento por distancia: no pierde el blanco.
'- Tiro barato (-1 con shootval 0) contra rivales de poca energia y
'  poco poison: no se funde disparando caro a los enjambres.
'- Paralizado (vloc = .shoot, venval -2): shootval 1, y no purga waste.
'- Disfraces: .out7 de This'n'That, .out8/.out9 de la familia BETA, y
'  un gen muerto con los conteos de .aimdx de Republican Wasp y de ojos
'  y .shoot de Multiply4: lo toman por uno de los suyos y no le tiran.

def dif 61

'Lazos ajenos: cortarlos en el acto
cond
*.numties 0 >
start
*.tiepres .deltie store
stop

'Disfraz: la cuenta de .out7 con que This'n'That reconoce a los suyos
cond
start
469 *.robage 469 mod sub .out7 store
500 .out8 store
510 .out9 store
stop

'Disfraz (nunca corre): tantos giros como Republican Wasp, y tantos
'ojos y tiros como Multiply4
cond
*.robage -1 =
start
0 .aimdx store
0 .aimdx store
0 .shoot store
0 .shoot store
*.eye1 *.eye2 *.eye3 *.eye4 *.eye5 *.eye6 *.eye7 *.eye8 *.eye9 *.eye1 *.eye2
stop

'Nadie lo fija
cond
*.fixed 0 !=
start
0 .fixpos store
stop

'Nacimiento: ojos en abanico y media vuelta
cond
*.robage 0 =
start
800 .eye1dir store
300 .eye1width store
600 .eye2dir store
300 .eye2width store
400 .eye3dir store
300 .eye3width store
200 .eye4dir store
300 .eye4width store
-200 .eye6dir store
300 .eye6width store
-400 .eye7dir store
300 .eye7width store
-600 .eye8dir store
300 .eye8width store
-800 .eye9dir store
300 .eye9width store
100 .eye5width store
628 .aimdx store
stop

'Pariente: el ADN del que mira cuenta lo mismo que el suyo
cond
*.eyef 0 >
start
*.refeye *.myeye sub abs *.refshoot *.myshoot sub abs add *.refup *.myup sub abs add *.refaimdx *.myaimdx sub abs add *.refdx *.mydx sub abs add .dif store
stop

cond
*.eyef 0 =
start
1 .dif store
stop

'Buscar: el foco recorre los ojos
cond
*.eyef 0 =
*.dif 0 = or
start
*.focuseye 5 add 1 add 9 mod 4 sub .focuseye store
stop

'Nada a la vista: rondar
cond
*.eye1 *.eye2 add *.eye3 add *.eye4 add *.eye5 add *.eye6 add *.eye7 add *.eye8 add *.eye9 add 0 =
start
70 .aimdx store
*.maxvel *.vel sub 0 floor 3 div .up store
stop

'Rival en el foco: encararlo y seguirle el paso
cond
*.eyef 0 >
*.dif 0 !=
start
*.refxpos *.refypos angle .setaim store
0 .focuseye store
*.refveldx .dx store
*.refvelup .up store
stop

'Acortar: cuanto mas lejos, mas rapido
cond
*.eyef 0 >
*.dif 0 !=
start
*.refxpos *.refypos dist 8 div 40 sub 0 floor 60 ceil *.refvelup add .up store
stop

'Rival a tiro, sin lazos: golpe donde no hay coraza
cond
*.eyef 5 >
*.dif 0 !=
*.numties 0 =
start
-6 .shoot store
24 .shootval store
*.refshell *.refpoison >
-1 .shoot store
*.refnrg 800 <
*.refpoison *.body 5 div 20 add <
and
-1 .shoot store
0 .shootval store
stop

'Energia de sobra a musculo
cond
*.nrg *.body 2 mult >
start
*.nrg *.body 2 mult sub 10 div 100 ceil .strbody store
stop

'Poca energia: comer musculo
cond
*.nrg *.body 2 mult 2 div <
start
100 .fdbody store
stop

'Guardia: shell
cond
*.shell 3 mult *.body <
*.nrg 500 >
start
100 .mkshell store
stop

'Guardia: poison (proporcional, y nunca menos de 300: rechaza los lazos que chupan 1000)
cond
*.poison 16 mult *.body <
*.poison 300 < or
*.nrg 500 >
start
100 .strpoison store
stop

'Guardia: slime contra virus
cond
*.slime 500 <
*.nrg 300 >
start
500 *.slime sub .mkslime store
stop

'Dividirse
cond
*.nrg 3000 >
*.body 1800 >
start
20 .repro store
628 .aimdx store
stop

'Purgar waste por detras (no paralizado: le cambiarian el tiro)
cond
*.waste 100 >
*.paralyzed 0 =
start
-4 .shoot store
*.waste .shootval store
.backshot inc
stop

'Paralizado: si le hacen tirar energia (-2), que sea casi nada
cond
*.paralyzed 0 !=
start
1 .shootval store
stop

'Limpieza al final: lo que un virus pudo dejar escrito
cond
start
0 .vshoot store
0 .mkvirus store
0 .delgene store
stop

cond
*.repro 20 !=
start
0 .repro store
stop
end
