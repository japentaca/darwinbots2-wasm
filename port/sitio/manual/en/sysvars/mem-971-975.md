Cells 971 to 975 are free memory for the bot, with one difference: when it
reproduces, the child is born with a copy of what the parent had in them. They
are already there in the child's first cycle, unconditionally: it does not matter
whether the birth tie is still there or breaks. In sexual reproduction they are
copied from the mother.

The rest of the child's free memory starts at 0, so these five cells (and
[[sysvars/mem-976-990|976–990]]) are the way to pass it data chosen by the parent
(of the memory, apart from these, it only inherits the [[.timer]], which keeps
counting): a heading, a lineage password, a generation counter. In this bot,
each founder picks a random heading and all its descendants point the same way:

```adn
' The founder picks a random heading and leaves it in 971
cond
*971 0 =
start
1255 rnd 1 add 971 store
stop

' Everyone, founder and children, aims at that heading
cond
start
*971 .setaim store
stop

' It reproduces at 10 cycles
cond
*.robage 10 =
start
50 .repro store
stop
```

The child is born with 971 already loaded, so the first gene does not roll again.
With two founders, two lineages form, each with its own heading ([[.setaim]],
[[op:rnd]]).

Like any free cell, nothing protects them: a memory shot or someone else's tie
can write to them. There is also a reset, tied to [[simulacion/mutaciones]],
that makes the child be born without genetic memory; it comes switched off and
the app does not let you enable it. More details in [[adn/memoria#memoria-genetica]].
